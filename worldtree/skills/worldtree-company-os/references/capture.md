# 記録と再利用

目的は、AI を介した個人の業務成果を組織の知識として蓄積し、他のメンバーの仕事へ還元すること。会話全文の収集や人物評価ではない。記録するのは、利用者に頼まれたとき、または提案して了承を得たときだけ。

## 提案のしかた

- 業務の区切りで、残す価値のある成果があれば、何を・どの種類で・どの閲覧範囲に残すかを 1〜2 文で示し、了承を得る。例：「今の結論『〇〇』を、承認待ちの意思決定の芽として WorldTree に残しますか（プロジェクト『△△』の範囲）」。
- 同じ区切りの候補はまとめて 1 回で提案する。作業を遮って何度も尋ねない。
- 断られた内容は、同じ会話で再提案しない。
- 記録の了承は、メッセージ送信、他人へのタスク割当、全社公開、行動の観察の記録の了承を含まない。それぞれ別に確認する。

## 何を残すか

| 成果                                                       | 記録                                                                      |
| ---------------------------------------------------------- | ------------------------------------------------------------------------- |
| 採用案・方針が決まり、理由が示された                       | `worldtree_record_decision`。採用案、理由、実際に検討した代案、背景、出典 |
| 顧客事実、調査結果、失敗原因、検証結果、ノウハウが得られた | `worldtree_create_knowledge_candidate`。知識、根拠、適用条件、不確実性    |
| 繰り返し使う進め方が固まった                               | `worldtree_create_skill_candidate`。発動条件、手順、停止条件、適用範囲    |

- 長い会話の終了を待たず、調査結果の確定・比較の結論・業務の区切りで提案する。
- 雑談、仮の案、同じ内容の繰り返しは提案しない。
- 実用的な調査結果は、未解決の点があっても残す価値がある。確認済みと未確認を分けて書く。
- 決定の理由が足りない場合は創作しない。質問するか、理由が未確認の検討メモとして知識の芽に残す（どちらも了承を得てから）。
- AI が思いついただけの未合意の方法は、確定した手順として保存せず、提案として扱う。

## 他の人が使える記録

- 誰が何をどの状況で判断・調査したかを、本人が述べた内容、接続中の利用者（記録者）の情報、元記事に基づいて残す。記録した人が決定者とは限らない。発言者が不明なら不明とする。人物評価や、保有知識のランキングを作らない。
- 結論だけでなく、背景、理由、比較、前提、適用先、注意点、未解決事項を残す。日付・金額・固有名詞・却下理由を落とさない。
- 外部調査は、実際に参照した URL・資料名・確認日と、引用と推論の区別を記録する。第三者の文章の全文を複製しない。議事録の原文を保存するよう頼まれたときは、[WorldTree の操作手順](operations.md)の原文保持に従う。
- タイトルには、検索される主題・案件名を含める。projectIds とタグは現在の一覧から解決する。秘密情報を全社公開の「一般」へ流さない。安全な保存先が決まらないときは、必要な範囲だけ確認する。
- 事前に承認済みの記事・決定を検索し、新しい情報なら差分と以前の記録を明記する。訂正は新しい芽として記録し、確定済みの情報を黙って上書きしない。
- 会話内で成功した保存の ID と内容を保持し、同じ芽を再送しない。検索には未承認の芽が出ないので、0 件を根拠にタイムアウトした保存を再送しない。

## 承認と還元

- 保存結果の isSprout / reviewStatus などを確認し、「承認待ちの芽として記録しました」と短く伝える。draft / decided といった業務上の状態だけで、人が承認済みと判断しない。
- 他のメンバーの仕事を始めるときは、関連する承認済みの記事・決定を検索し、本文・適用条件・新旧を確認して利用する。誰が書いたかだけで信頼しない。
- 未承認の芽は、通常の検索や回答の根拠に出ない。保存直後から全員が使えるとは伝えず、人が画面で承認したあと、閲覧権限のあるメンバーが参照できると説明する。承認を省くために確定済みの記事を複製しない。

## 範囲と失敗

- 仕訳・記帳・決算などの経理作業そのものは対象外。経費精算などの社内ルールについての記録は対象。
- 「残さないで」という指示を優先する。私生活・健康などの不要な情報や、パスワード・トークンは記録しない。
- 必要なツールがない、保存が拒否された、適切な公開範囲が分からない、タイムアウトした、のいずれかなら、未保存または結果不明と明示する。
- AI のメモリ機能への保存で、WorldTree への記録を代替しない。会話全体の記録は行わない。
