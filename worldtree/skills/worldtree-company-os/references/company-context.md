# 会社識別

1. WorldTree の接続を識別し、`worldtree_whoami` を読む。組織 ID、orgName、ユーザー ID、接続識別子を会話内に保持する。表示は会社名（orgName）を使い、orgSlug を会社名とみなさない。
2. 接続が複数あり対象が未指定なら、読み取りで識別できる範囲を確認する。本人の会社か顧客の会社か判断できなければ短く確認し、接続を横断してデータを混ぜない。
3. 会社の正式名称や通称を確かめる必要があるときだけ、orgName と「会社概要」「会社基本情報」等の短い検索を用い、該当記事の全文から正式名称・通称・読み方・略称を確認する。語や記事タイトルを固定の必須項目にしない。専用の会社プロフィール取得ツールの存在を仮定しない。
4. 別名は組織 ID に紐付け、出典を保持する。明示されたユーザーの補足も会話内で使えるが、自動で会社記事や長期メモリに書き込まない。音の類似だけで会社を同一視しない。
5. 「うち・弊社・自社・当社」は接続と会話の文脈が整合する場合だけその会社へ解決する。引用内の「弊社」は話者の会社であり、ユーザーの会社とは限らない。
6. メモリは検索語の補助。古い会社名・所属で現在の接続先を上書きしない。個人ワークスペースを法人とみなさない。
7. 組織を切り替えたら、以前の会社の別名・ID・記事・手順のキャッシュを切り離す。

1 つの接続は 1 つの組織に固定されている。質問に接続先と違う会社名が含まれ、検索しても見つからないときは、「社内に情報がない」と結論せず、接続先の組織が違うことを伝え、その会社の接続に切り替えるよう案内する。

`worldtree_whoami` に toolCount があれば、同じ接続の WorldTree ツールだけを数えて比較する。別の接続のツールは数に含めない。toolCount が 0 のときはサーバー側の算出の失敗で、数の不一致ではない。不一致はツール一覧の同期の問題として伝え、再接続を依頼する。数だけから廃止されたツールを特定しない。不足しているツールや別の版のツールを推測で呼ばない。
