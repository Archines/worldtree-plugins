# WorldTree plugin

WorldTree の MCP サーバーに Claude を接続し、会社固有の文脈を踏まえて調べもの・相談・タスク管理を進めるためのプラグインです。

## 含まれるもの

| 種類         | 名前                                                     | 内容                                                                                                                                                           |
| ------------ | -------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| MCP サーバー | `worldtree`                                              | `https://worldtree.archines.co.jp/api/mcp`（Streamable HTTP・OAuth 2.1）。記事・タスク・意思決定・プロジェクト・メンバー・バリューなどを扱うツールを提供します |
| スキル       | `worldtree-company-os`（WorldTree 共通業務アシスタント） | 会社固有の情報が要る依頼で WorldTree を参照し、結論と出典を返します。WorldTree への書き込みは、頼まれたとき、または了承を得たときだけ行います                  |

- `.mcp.json` にはトークンなどの認証情報を書いていません。認証は、利用者が OAuth でサインインして行います。
- スキルの `agents/openai.yaml` と `assets/icon.svg` は、同じスキルを ChatGPT や Codex で使うときの表示設定です。Claude では使いません。

## インストール

Claude Code で次を実行します。

```text
/plugin marketplace add Archines/worldtree-plugins
/plugin install worldtree@worldtree-plugins
```

`Archines/worldtree-plugins` の形は、既定で SSH を使って GitHub から取得します。GitHub に SSH 鍵を登録していない場合は、1 行目を HTTPS の URL に置き換えてください。

```text
/plugin marketplace add https://github.com/Archines/worldtree-plugins.git
```

1. `/mcp` を開き、`plugin:worldtree:worldtree` を選んでサインインします。ブラウザで WorldTree のログイン画面が開きます。
2. WorldTree のアカウントでログインし、接続する組織を選んで許可します。1 つの接続は 1 つの組織に固定されます。
3. 「どの組織につながってる？」と聞くと、接続先の組織名を確認できます。

claude.ai のコネクタで WorldTree をすでに追加している場合、Claude Code では同じツールが 2 組見えます。どちらか一方を無効にしてください。

## 必要なもの

- WorldTree のアカウントと、WorldTree を利用中の組織への所属
- 使えるツールは組織内のロールで変わります（owner / admin は 49、member は 46、guest は閲覧中心の 18）。削除系のツールは admin 以上にだけ表示されます。

## スキルの使い方

スキルは、会社や業務に固有の情報が必要な依頼で自動的に使われます。「WorldTree で調べて」と言わなくても、「うちの」「弊社の」、会社名や案件名を含む依頼が対象です。`/worldtree:worldtree-company-os` で明示的に呼び出すこともできます。

| 依頼の例                                                    | スキルが行うこと                                                                   |
| ----------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| 「うちの経費精算のルールを教えて」                          | 記事を検索して本文を読み、結論と出典（記事へのリンク）を返す                       |
| 「A 社の案件、前回の宿題はどうなってる？」                  | プロジェクト・タスク・議事録・決定を横断して状況をまとめる                         |
| 「なぜ今の料金体系にしたんだっけ」                          | 意思決定と出典記事、確認済みのリンクをたどって経緯を説明する                       |
| 「今週が期限の自分のタスクを一覧にして」                    | 自分が作成または担当している未完了タスクを期限順にまとめる                         |
| 「この議事録を WorldTree に保存して、決まったことも残して」 | 原文を記事として保存し、決まったことを承認待ちの意思決定の芽として記録する         |
| 「今日やることと返信漏れをまとめて」                        | WorldTree のタスクと、利用者が別に接続しているメール・カレンダーを照合してまとめる |

- 朝の確認に使うメール・カレンダーの接続は、このプラグインには含まれません。利用者が別に接続している場合だけ、頼まれたときに読みます。
- 毎朝の確認を定期実行にするのは、頼まれたときだけです。

### 記録について

- WorldTree への書き込みは、利用者に頼まれたとき、またはスキルが「残しますか」と提案して了承を得たときだけ行います。
- スキルが提案して残す意思決定・知識・スキルの候補は、承認待ちの「芽」になります。WorldTree の画面で人が確定するまで、検索や他のメンバーの回答には出ません。
- 利用者が明示的に頼んだ記事の保存（議事録など）、タスクの作成、確定済みとしての意思決定の登録は、すぐに反映されます。記事の閲覧範囲は、紐付けたプロジェクトで決まります。
- 行動の観察（`worldtree_record_observation`）は、記録する内容を示し、本人の了承を得てから記録します。照合が有効な環境では、記録後に WorldTree のサーバーが外部の AI 事業者（OpenAI）でバリューとの照合を行います。

## うまく動かないとき

- **WorldTree のツールが見えない**：`/mcp` でサインインの状態を確認し、必要ならサインインし直してください。
- **別の組織の情報が出る・出ない**：接続先は OAuth のときに選んだ組織です。組織を変えるには、接続を解除してからサインインし直し、同意画面で組織を選び直してください。
- **ツールの数が合わない**：WorldTree 側でツールが増減したあと、クライアントの一覧が古いままのことがあります。接続し直してください。
- **権限のエラー**：ロールによって使えない操作があります。組織の管理者に確認してください。

詳しい手順は [利用者向けドキュメント](https://worldtree.archines.co.jp/connectors/worldtree) にあります。
